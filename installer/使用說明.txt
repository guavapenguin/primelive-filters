============================================
   primelive 一鍵濾鏡 — 使用說明
============================================

安裝時已經一起幫你裝好 OBS（直播軟體）了，不用另外裝。

────────────────────────────────
【第一次使用 — 先看濾鏡】
────────────────────────────────
1. 桌面點兩下「primelive 一鍵濾鏡」→ 跳出預覽視窗。
2. 看不到自己的臉？按鍵盤的 N 鍵切換攝影機（會自動換下一個）。
3. 視窗下方一排大按鈕，滑鼠點一下就換濾鏡。
   （也可以按按鈕上 [ ] 裡的鍵，例如按 1、2、3…）
4. 想關閉：按 Q。

────────────────────────────────
【換頭 / 面具 想喬位置】
────────────────────────────────
選到換頭類濾鏡（水豚頭、白熊、雙馬尾、花圈、光環）時：
  =  放大      -  縮小
  [  往上      ]  往下
喬到剛好蓋住頭之後，按 O 存起來（下次就記得了）。

────────────────────────────────
【要直播時】
────────────────────────────────
1. 打開 OBS（桌面或開始選單裡）。
2. 下方「來源」按 +  → 視訊擷取裝置 → 確定
   → 「裝置」選【OBS Virtual Camera】→ 確定。
   ★ 這就是套了濾鏡的畫面。
3. 右下「設定」→ 串流 → 服務選你的平台（YouTube / Twitch…）
   → 貼上平台給你的「串流金鑰」→ 確定。
4. 按右下「開始串流」→ 開台！

────────────────────────────────
【重要提醒】
────────────────────────────────
• primelive 濾鏡視窗要「開著」，OBS 才看得到濾鏡畫面。
• 不要在 OBS 按它自己的「啟動虛擬攝影機」，會跟濾鏡打架。
• 第一次開可能要等幾秒載入，屬正常。

有問題就把畫面截圖傳回來問。祝開台順利！
