# 引擎防 lag 優化（2026-08-12）

參考商用美顏濾鏡「順」的關鍵原理（永不卡在抓圖、輸出穩定 fps、畫質隨硬體自動縮放），
用**我們自己的引擎**重寫,不引入任何第三方產物。改動集中在 `primelive_engine.py`,
濾鏡的視覺效果**完全不變**(全速時輸出與原本一致)。原始檔備份為 `primelive_engine.py.bak-preopt`。

## 改了什麼

1. **背景抓圖執行緒（`CameraThread`）**
   抓圖從主迴圈搬到背景執行緒,主迴圈永遠拿「最新一格、丟掉舊格」。
   → 不再被相機 I/O 卡住、延遲不會愈積愈久。
   實測(同機同輸入)：吞吐量約 **12.5 → 24.6 fps**(抓圖與運算重疊)。

2. **自動調解析度（`Adaptive`）**
   量測每格「純處理耗時」,跟不上目標 fps 就把處理解析度往下降(最低到 `--min-scale`,預設 50%),
   有餘裕再升回 1.0。**在縮小的畫面跑整條管線,最後再放大送出**;強機維持原畫質、弱機自動變順。
   換背景遮罩/貼圖定位都跟著處理解析度走,不會錯位。

3. **MediaPipe 可選 GPU（`--gpu`）**
   嘗試用 GPU delegate 跑臉部/分割,失敗自動退回 CPU(Windows 上 GPU 不一定支援,故預設關)。

4. **只有虛擬人濾鏡才算 blendshapes**
   之前每格都算嘴型 blendshapes,現在只有含 `lipsync` 的濾鏡才開,省一點 CPU。

## 新增參數（都有安全預設,不加也會自動防 lag）

| 參數 | 預設 | 說明 |
|---|---|---|
| `--target-fps N` | 30 | 目標 fps,自動調解析度以維持它 |
| `--min-scale F` | 0.5 | 自動降解析度的下限(0.5＝最低降到一半) |
| `--no-adaptive` | 關 | 關閉自動調解析度(固定畫質) |
| `--no-threaded` | 關 | 關閉背景抓圖執行緒(除錯用) |
| `--gpu` | 關 | 嘗試 GPU 跑 MediaPipe(失敗退回 CPU) |
| `--fast` | 關 | (原有)擷取降 540p;可與自動調解析度並用 |

預覽窗左上角會顯示 `fps~ / scale / 尺寸`,方便現場判斷順不順。
